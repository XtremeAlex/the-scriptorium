# the-scriptorium

Raccolta di script che automatizzano attività ripetitive, organizzati per ambito.

## Info sul progetto

Questo repository raccoglie script di utilità nati per eliminare attività ripetitive, suddivisi in cartelle tematiche.

## Contenuto

- [`certsnatcher/`](certsnatcher/) — script legati a CertSnatcher (gestione ed elaborazione certificati)
- [`k8s/`](k8s/) — script di supporto per Kubernetes
